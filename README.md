# 季の美

「四季でめぐる、日本の伝統色。」をコンセプトにした、レスポンシブな色彩カタログサイトです。

## Project Overview

日本の伝統色を春・夏・秋・冬の季節ごとに紹介しています。カード型レイアウトと詳細モーダルを通して、CSS Grid、レスポンシブデザイン、アクセシビリティの基本を実践する学校課題です。

## Pages

- `index.html` - 八色のメインカタログ
- `page01.html` - 春の色（桜色・若草色）
- `page02.html` - 夏の色（翡翠色・瑠璃色）
- `page03.html` - 秋の色（山吹色・柿色）
- `page04.html` - 冬の色（銀鼠・墨色）

## Features

- モバイルファーストのレスポンシブデザイン
- CSS Gridによる1・2・4カラムレイアウト
- キーボード操作に対応した詳細モーダル
- 季節の写真を使ったカード型レイアウト
- セマンティックHTMLと現在位置を示すナビゲーション
- 外部ライブラリ不要、ローカル環境で動作

## Technologies

- HTML5
- CSS3 / CSS Grid
- Vanilla JavaScript
